# 🚀 Project Rebrand & Monetization Strategy

> **Goal:** Establish a professional brand that stands out in the MCP ecosystem and build a sustainable business model.

## 🎯 Proposed New Name: **RepoLens**

### Why RepoLens?
- **Short & Memorable:** Easy to say, spell, and remember.
- **Clear Value:** "Lens into repositories" — instantly understood.
- **Professional:** Sounds like a serious tool, not a toy.
- **Available:** `repolens` is free on npm and GitHub.

### Brand Identity
- **Tagline:** "Your codebase, illuminated."
- **Visual:** Magnifying glass + circuit pattern logo.
- **Colors:** Electric blue/purple (tech) with clean whites.
- **Voice:** Precise, intelligent, empowering.

## 💰 Monetization Strategy

### Phase 1: Build (Free & Open Source)
- **Goal:** Maximize adoption and community.
- **License:** AGPL-3.0 (current).
- **Features:** Everything you have now.

### Phase 2: Grow (Freemium Model)
| Tier | Price | Features |
|------|-------|----------|
| **Free** | $0 | Core search (JS/TS/PHP), ripgrep, AST |
| **Pro** | $10/month | Semantic search, cross-repo graphs, live indexing |
| **Enterprise** | $50/month/user | SSO, audit logs, remote repos, priority support |

### Phase 3: Scale (Ecosystem)
- **Marketplace:** Host language extensions (15% cut).
- **Partnerships:** IDE vendors, AI platforms.
- **Services:** On-premise setup, custom development.
